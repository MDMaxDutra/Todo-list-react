# Todo React Avançado 🚀

Aplicação de lista de tarefas desenvolvida com React utilizando recursos avançados.

## Tecnologias utilizadas

- React
- Vite
- Tailwind CSS
- Context API
- Hooks
- useMemo
- React.memo

## Funcionalidades

- Adicionar tarefas
- Remover tarefas
- Marcar como concluída
- Filtrar tarefas
- Persistência com localStorage

## Como executar o projeto

```bash
npm install
npm run dev
